# AnchorStack MVP

A React/Vite MVP for a military-focused passive-income financial tools app.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite gives you, usually:

```text
http://localhost:5173
```

## Deploy to Vercel

1. Create a GitHub repo
2. Upload these files
3. Go to Vercel
4. Import the repo
5. Click Deploy

## Monetization ideas

- Stripe subscription for premium calculators
- Affiliate links for military discounts
- Sponsored military finance content
- SEO articles around PCS, BAH, TSP, deployment savings
